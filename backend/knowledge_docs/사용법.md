# RAG 문서 임베딩 생성 가이드

## 🚀 빠른 시작

### 1. 문서 추가
`backend/knowledge_docs/` 폴더에 PDF, Markdown, 또는 텍스트 파일을 추가합니다.

```bash
cp your_document.pdf backend/knowledge_docs/
```

### 2. 임베딩 생성 (버튼 클릭)

**방법 A: Swagger UI 사용 (가장 쉬움)**

1. 브라우저에서 열기: http://localhost:8000/docs
2. `/admin-api/knowledge/embed-all` 엔드포인트 찾기
3. `Try it out` 클릭
4. `Execute` 버튼 클릭
5. 결과 확인!

**방법 B: curl 명령**

```bash
curl -X POST http://localhost:8000/admin-api/knowledge/embed-all
```

### 3. 채팅에서 사용
Admin 채팅에서 질문하면 자동으로 문서를 검색합니다!

## 📊 응답 예시

```json
{
  "total_files": 4,
  "processed": 2,
  "failed": 0,
  "skipped": 2,
  "details": [
    {
      "file": "README.md",
      "status": "success"
    },
    {
      "file": "test_rag.md",
      "status": "skipped",
      "reason": "이미 임베딩 존재"
    }
  ]
}
```

## ✨ 특징

- ✅ **중복 방지**: 이미 임베딩이 있는 파일은 자동으로 건너뜀
- ✅ **파일 해시**: 파일 내용으로 중복 체크
- ✅ **자동 감지**: PDF, MD, TXT 파일 자동 인식
- ✅ **실시간 진행**: 각 파일의 처리 상태 확인 가능

## 🔧 고급 사용법

### 특정 파일만 처리
```bash
curl -X POST http://localhost:8000/admin-api/knowledge/ingest \
  -H "Content-Type: application/json" \
  -d '{
    "path": "/app/knowledge_docs/specific_file.pdf",
    "title": "특정 문서"
  }'
```

### 문서 목록 조회
```bash
curl http://localhost:8000/admin-api/knowledge/documents
```

### 문서 삭제
```bash
curl -X DELETE http://localhost:8000/admin-api/knowledge/documents/{doc_id}
```
